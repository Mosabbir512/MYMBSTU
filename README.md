# MBSTU CAMPUS MANAGEMENT SYSTEM

A web-based platform designed for the students of 
Mawlana Bhashani Science and Technology University (MBSTU)
to easily access all essential university services from one place. 
This project integrates multiple student services, reducing paperwork
and saving time through a centralized system.


 University Diary
- Instantly access contact information of **teachers**, **students**, and **staff**.
- Always up-to-date with newly joined personnel.
- No need to ask friends or visit departments.

 Hall Management
- Online application for **hall seats**, **ID cards**, **lost certificates**, and **attestation papers**.
- Track hall seat application status (e.g., approved/rejected).
- View seat availability and notices online.

 Medical Center
- Book doctor appointments online.
- Get e-prescriptions via email.
- Use student ID for quick identification.
- Emergency helpline and ambulance contacts provided.

 Admission Portal
- Apply for admission online.
- Track admission deadlines and result announcements.
- View and download notices and forms easily.


Tech Stack

| Technology   | Description                                                                |

| **HTML**     | For structuring web pages.                                                 |
| **CSS**      | For styling the web pages.                                                 |
| **JavaScript** | For adding interactivity and dynamic behavior.                           |

| **JPA (Hibernate)** | To interact with the database using Java objects.                   |
| **PostgreSQL** | Open-source relational database to store application data.               |



 Existing Issues:
 
- Manual paperwork and physical visits for hall, medical, and ID card services.
- No centralized source for teacher, staff, or student information.
- No online medical system or appointment booking.
- Inefficient tracking of hall applications and admission notices.

 Proposed Solutions

- Centralized web app for all student services.
- Quick and paperless online form submission.
- Real-time tracking of application status.
- Online medical booking and digital prescriptions.
- Always-updated directory of students and university staff.
